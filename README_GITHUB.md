# Busan 2027 GitHub Pages 使用方式

1. 登入 GitHub。
2. 建立一個新的 Public repository，例如 `busan-2027`。
3. 把 `index.html` 上傳到 repository 根目錄。
4. 進入 **Settings → Pages**。
5. 在 **Build and deployment**：
   - Source：`Deploy from a branch`
   - Branch：`main`
   - Folder：`/(root)`
6. 儲存後等幾分鐘。
7. 網址通常會是：
   `https://你的帳號.github.io/busan-2027/`

## 之後更新
直接修改 GitHub 裡的 `index.html`，或重新上傳覆蓋，再 Commit 即可。

## 隱私
網站裡的採買勾選與記帳使用瀏覽器 `localStorage`。
它們不會自動寫回 GitHub，也不會因 GitHub Pages 是公開網站就公開你的實際記帳內容。
