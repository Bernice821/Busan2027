Backup & print

備份與列印

你的勾選與記帳資料預設只存在目前瀏覽器的 localStorage，不會自動上傳到 GitHub。

放到 GitHub Pages
  1. 建立 GitHub Repository，例如 busan-2027，設為 Public。
  2. 把這個 index.html 上傳到 Repository 根目錄。
  3. Settings → Pages → Source 選 Deploy from a branch。
  4. Branch 選 main、資料夾選 /(root) → Save。
  5. 完成後網址通常會是 https://你的帳號.github.io/busan-2027/。
公開 GitHub Pages 只會公開這個「空白記帳版網站」。你在手機上輸入的實際花費留在瀏覽器，不會因為網站在 GitHub 就自動公開。
